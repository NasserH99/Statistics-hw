Exercise 1 – Riemann and Lebesgue integration

1.1 The two ideas

Riemann: cut the domain [a, b] into N small intervals of width Δx and add the rectangles.
SN = Σ f(xi*) · Δx
I use the midpoint rule: xi* is the middle of each interval. Cost: N evaluations of f.
Lebesgue: cut the range of f into B bins [yj, yj+1) and measure how big the set of x where f falls in that bin is.
∫ f ≈ Σ yj* · μ( f−1[yj, yj+1) )
The preimage measure μ is estimated: I take M equally spaced points of the domain and count which fraction falls in each bin. Cost: M evaluations of f plus B counters.

Important honesty note: counting grid points to get the measure of a preimage is only an approximation of the Lebesgue idea, it is not a real measure-theoretic construction. That is exactly why it fails on the Dirichlet function (section 1.4).

1.5 Pathological functions

Dirichlet   f(x) = 1 if x is rational, 0 if irrational. In every subinterval there are both rationals and irrationals, so every lower sum is 0 and every upper sum is 1: not Riemann-integrable. The rationals are countable, so they have measure 0 and the Lebesgue integral is 1·0 + 0·1 = 0.

Thomae   f(p/q) = 1/q (lowest terms), f = 0 on irrationals. It is discontinuous only on the rationals (a set of measure 0), so it is Riemann-integrable with integral 0, and also Lebesgue-integrable with integral 0.

1.6 Observations for Exercise 1

  • Same limit. For Riemann-integrable functions both approaches converge to the same number (see the table in 1.3 and the convergence plot).
  • Accuracy. For smooth functions the midpoint rule is much better: its error goes like 1/N². The range-bin approach has two error sources, the bin width and the counting error of the preimage measure, so it is slower and irregular (the orange curve in 1.4 is bumpy); in my runs it is 2–3 orders of magnitude worse than Riemann for the same number of evaluations.
  • Step functions. Both give the exact answer. For the Lebesgue-style method this happens because the preimages are whole intervals and the two bin errors (+w/2 on the low value, −w/2 on the high value) cancel for the 50/50 split. It is a coincidence of this example, not a general rule.
  • Unbounded function 1/√x. Both are slow (error ≈ 1/√N), because the function blows up near 0 and no finite grid sees the spike. The Lebesgue view is the natural one here (the spike has small measure) but the grid-count estimate does not exploit that.
  • Cost. Riemann: N evaluations, one sum. Lebesgue-style: M evaluations, plus finding min/max, plus binning, so it is slower per evaluation, and it needs a way to measure preimages, which is the hard part in general.
  • Pathological. Here the two ideas really differ. Dirichlet: Riemann sums depend on the tags (1 or 0), Lebesgue gives 0. Thomae: both give 0. On a computer every float is a rational number, so a "rational/irrational" test on a grid always answers "rational": a program cannot see that the rationals have measure 0.

Exercise 2 – Numerical computation of the normal CDF

2.1 Mathematics

The standard normal CDF is
Φ(x) = (1/√(2π)) ∫−∞x e−t²/2 dt
Why no elementary formula? (Liouville). Liouville's theorem says: if f and g are rational functions, then ∫ f(t)·eg(t) dt is an elementary function if and only if there is a rational function h with
h′ + g′·h = f.
Here f = 1 and g = −t²/2, so g′ = −t and we would need h′ − t·h = 1.
  • If h is a polynomial of degree d, then t·h has degree d+1 while h′ has degree d−1, so h′ − t·h has degree d+1 ≥ 1 and cannot be the constant 1.
  • If h has a pole of order k ≥ 1 at some point c, then h′ has a pole of order k+1 and t·h has a pole of order at most k, so the pole of h′ cannot be cancelled.
So no rational h exists and e−t²/2 has no elementary antiderivative. The function Φ is perfectly well defined, it just cannot be written with polynomials, exp, log, sin, … in finite form.

Special function. We give the missing function a name, the error function:

erf(z) = (2/√π) ∫0z e−t² dt   ⇒   Φ(x) = ½ [ 1 + erf( x/√2 ) ]
This is an exact analytic representation, but it only moves the problem: to get a number we still need an algorithm for erf (integration, series, approximation). Also, by symmetry Φ(−x) = 1 − Φ(x), and Φ(x) = ½ + ∫0x φ(t) dt, so I only need a finite integral over [0, |x|], with no arbitrary cut-off at −∞.

2.2 Methods implemented

  1. Trapezoid rule on [0, |x|] with n subintervals (error ~ 1/n²).
  2. Simpson rule on [0, |x|] with n subintervals (error ~ 1/n⁴).
  3. erf Maclaurin series: erf(z) = (2/√π) Σ (−1)k z2k+1 / (k!(2k+1)), with z = x/√2. Signs alternate, so for large |x| big terms cancel and precision is lost.
  4. Direct series without alternating signs: Φ(x) = ½ + φ(x)·( x + x³/3 + x⁵/(3·5) + x⁷/(3·5·7) + … ). All terms have the same sign, so no cancellation, and the terms are built by one multiplication each. This is the method I call "efficient".
  5. Fast erf approximation (Abramowitz & Stegun 7.1.26): a degree-5 polynomial in t = 1/(1+0.3275911·z) times e−z²; guaranteed error ≤ 1.5·10⁻⁷, constant cost, but it cannot be made more accurate.

2.6 Conclusions for Exercise 2

  • Φ has no elementary closed form (Liouville). The erf function gives an exact representation, but computing it still needs numerics.
  • Simpson converges much faster than the trapezoid rule (error ~ n⁻⁴ vs n⁻²) at almost the same price per point.
  • The erf Maclaurin series reaches machine precision for small |x| with few terms, but loses accuracy for large |x| (alternating terms).
  • The non-alternating series Φ(x) = ½ + φ(x)·Σ x2k+1/(1·3·5···(2k+1)) is stable and reaches ~10⁻¹⁶ with a few dozen multiplications. It is the best method here.
  • The A&S polynomial is the cheapest and good enough when 7 digits are enough, but its error has a floor.
