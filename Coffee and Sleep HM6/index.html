Coffee and Sleep

Are the number of coffees someone drinks and the quality of their sleep independent? This page builds the contingency table from raw pairs, tests it with chi-square, and says what the result does and does not mean.

Theory

In probability

Two variables X and F are independent when knowing one tells you nothing about the other. For every pair of values (i, j):

P(X = i, F = j) = P(X = i) · P(F = j)

Same idea in words: the conditional distribution P(F | X = i) is the same for every i, and it equals the marginal P(F).

In statistics

From n observations we count nij pairs. If X and F were independent, we would expect:

Eij = (row total × column total) / n
χ² = Σ (O − E)² / E   df = (R − 1)(C − 1)

A real sample is never exactly independent, so the test asks if the gaps between O and E are bigger than chance would give.

Data

Contingency table and marginal frequencies

Each cell nij counts the people with X = i and F = j. The last row and last column are the marginal frequencies: the totals for each variable alone.

Conditional frequencies

Each table divides the counts by a row total or a column total. Under independence all rows of the first table would be equal to its last row, and all columns of the second table equal to its last column.

Same thing as a picture

Expected frequencies under independence

These are the counts we would see if the two variables did not affect each other, with the same row and column totals.

Chi-square test

H₀: and are independent.

H₁: and are associated.
